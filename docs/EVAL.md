# EVAL — 評価の決まり

指標は自作しない。音声認識で標準的に使われているものだけを使う。

## 指標

| 指標 | 何を測るか | 計算 |
|---|---|---|
| MER(混合誤り率)— 主指標 | 日英混在の発話全体の正確さ | 日本語は1文字、英語は1単語(ラテン文字の連続)を1単位として編集距離を数え、正解の単位数で割る |
| CER | 日本語部分の正確さ | 文字単位の編集距離 ÷ 正解の文字数 |
| WER | 英語部分の正確さ | 単語単位の編集距離 ÷ 正解の単語数 |
| B-WER / U-WER | 辞書語(`bias_terms.txt`)とそれ以外の誤り率 | 正解中の辞書語だけ / それ以外だけで誤りを数える。辞書で寄せすぎた副作用は U-WER に出る |
| 遅延 p50 / p95 | 話し終わりから文字が確定するまで | ミリ秒で記録し、分位点で出す(平均は使わない) |
| RTF | エンジン単体の速さ | 処理時間 ÷ 音声の長さ |

MER の単位の切り方は、Amazon のコードスイッチング研究(中国語と英語、ICASSP 2021)の慣例に合わせた。日本語で同じ切り方が標準かは**未確認**。第1週に先行研究で確かめ、違えばここを直してから数字を出す。

## 採点前の正規化(固定、途中で変えない)

1. Unicode NFKC(全角英数字 → 半角)
2. 英字を小文字に
3. 句読点と記号を削除(`+` と `#` は残す。C++、C# のため)
4. 連続する空白を1つに

## データ

| セット | 場所 | git | 用途 |
|---|---|---|---|
| 自分のテストセット v1(50発話) | `data/testset/v1/` | 入れない | 主評価。凍結 |
| 公開データの固定セット(10発話程度) | `eval/fixtures/` | 利用条件を確認してから | CI と回帰チェック |

iPhone の音声入力(手で書き起こして記録)、whisper.cpp、Vosk、Gemini の文字起こし。
